# Fork — 2-minute demo script

Record on a phone (dev build or Expo Go) or in the web build at phone size. Use a fresh install so onboarding shows. **Live AI and RevenueCat Test Store must be configured** (see `FINAL_RELEASE.md`). If the network misbehaves, use the bundled sample (Home → *See an example*). It is labelled “Sample” on screen.

| Time | On screen | Voice-over |
|---|---|---|
| 0:00–0:08 | Fork logo, then onboarding page 1 with the fork drawing itself | “What if AI didn’t tell you what to choose — but let you explore what each choice changes? This is Fork.” |
| 0:08–0:20 | Skip → Home → **Explore a decision** → type *“Should I buy a new laptop now or keep my current one for another year?”* → **Build my paths** | “I describe a decision in my own words. That’s all it needs.” |
| 0:20–0:45 | Analysing state → the fork draws itself: A, B, C | “Fork maps it into genuinely different paths: buy now, keep it a year, or fix it up and decide later. It’s a map of my options, not a verdict.” |
| 0:45–1:10 | Tap **A** → scroll: what changes, upside, tradeoffs, what could go wrong, *this path assumes* → **Path B** | “Each path shows what changes, the tradeoffs, what could go wrong, and exactly what it assumes. No fake percentages, just honest uncertainty.” |
| 1:10–1:30 | **Compare** → toggle *Time* → rows sorted by difference | “I compare paths on what matters to me. The biggest differences rise to the top. Fork doesn’t score or rank them.” |
| 1:30–1:42 | **Choose a path** → pick C → type a note → **Keep this decision** → journal | “Then I choose. It’s my call, with a note to future me, saved in my decision journal.” |
| 1:42–1:54 | Home allowance → paywall → **Start Fork Pro** → Test Store sheet → purchase → open the sample fork: each path now shows where it could split next | “Fork Pro, powered by RevenueCat, unlocks unlimited decisions, deeper paths that show where each choice could split next, and richer comparisons.” |
| 1:54–2:00 | End card | “Fork. Don’t ask what to choose. Explore what each choice changes.” |

Tips: turn on Do Not Disturb, set the phone to about 50% brightness, and keep each screen still for a moment after a tap so viewers can read it.
