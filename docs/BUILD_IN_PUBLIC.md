**Day 2 — The core loop works** (attach `02-fork.png`)
> The fork is alive. Your decision is the root; each branch is a path you can tap.
> Under the hood: Claude with structured outputs → validated against a zod schema on the server *and* the app. If the model returns junk, users never see it. #BuildInPublic

**Day 3 — A design rule** (attach `04-compare.png`)
> Design rule for Fork’s Compare screen: **no scores, no winner.**
> Paths get qualitative readings (low/moderate/high + a plain-language note) and the rows where they differ most float to the top. The decision surfaces; the app never picks. #BuildInPublic
