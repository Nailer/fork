## App runtime

| Package | Version | Role |
|---|---|---|
| `expo` | ~57.0.25 | SDK, config, build tooling (Continuous Native Generation: no committed `ios/` or `android/`) |
| `react-native` | 0.86.3 | Native runtime (New Architecture) |
| `react` / `react-dom` | 19.2.3 | UI, plus the React Compiler lint rules |
| `react-native-web` | ~0.21.0 | Web target |
| `expo-router` | ~57.0.23 | File-based navigation in `src/app` |
| `typescript` | ~6.0.3 | Strict mode, `noUnusedLocals` |

## UI and motion

| Package | Role |
|---|---|
| `react-native-svg` 15.15.4 | The fork tree, Fork mark and all icons |
| `expo-linear-gradient` | Screen backdrops tinted with the path colour |
| `react-native-safe-area-context`, `react-native-screens` | Safe areas and native stack screens |
| `@expo-google-fonts/fraunces`, `@expo-google-fonts/inter` + `expo-font` | Display and UI type (per-weight imports keep unused font files out of the bundle) |
| `expo-haptics` | Selection, impact and success feedback on native |
| `expo-splash-screen`, `expo-status-bar`, `expo-system-ui` | Launch and system chrome |
