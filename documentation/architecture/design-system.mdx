Every colour, size and radius in the app comes from `src/theme/tokens.ts`. The direction: a calm ink background, warm ivory type and actions, and **one hue per path** so branches read instantly (always paired with an A–D letter).

## Colour

### Surfaces and lines

| Token | Hex | Use |
|---|---|---|
| `bg` | `#08090D` | App background |
| `bgTop` | `#0E1019` | Top of the backdrop gradient |
| `surface` | `#10131A` | Large surfaces |
| `card` | `#151922` | Cards, inputs |
| `raised` | `#1C2130` | Selected options |
| `line` | `#232836` | Hairlines |
| `lineStrong` | `#353B4C` | Input borders, inactive mark strokes |

### Type

| Token | Hex | Use |
|---|---|---|
| `text` | `#F5F3EE` | Primary text (warm ivory) |
| `textDim` | `#B4B8C5` | Body, small, subheading |
| `textFaint` | `#7F8496` | Captions, labels, placeholders |

All three pass WCAG AA on `bg` and `card`.

### Path colours

```ts
export const pathColors = ['#F5B65C', '#5ED3C0', '#A99BFF', '#FF8A7A'] as const; // A B C D
export const pathColor = (index: number) => pathColors[index % pathColors.length];
export const alpha = (hex: string, a: number) => hex + Math.round(a * 255).toString(16).padStart(2, '0');
```

## Spacing, radii, elevation, motion

```ts
space     = { xxs: 2, xs: 4, sm: 8, md: 12, lg: 16, xl: 24, xxl: 32, xxxl: 48 }  // 4-pt scale
radius    = { xs: 6, sm: 10, md: 14, lg: 18, xl: 24, pill: 999 }
elevation = { card: { boxShadow: '0 1px 0 rgba(255,255,255,0.04) inset, 0 10px 30px rgba(0,0,0,0.35)' },
              raised: { boxShadow: '0 1px 0 rgba(255,255,255,0.06) inset, 0 18px 50px rgba(0,0,0,0.5)' } }
motion    = { fast: 180, base: 260, slow: 420 }  // ms
MAX_CONTENT_WIDTH = 520
```

`boxShadow` works on the web and on the React Native New Architecture.

## Components (`src/components/ui.tsx`)

| Component | Purpose |
|---|---|
| `Screen` | Safe area + tinted `Backdrop` + centred 520 px column + optional scroll + sticky `footer` |
| `Backdrop` | Linear gradient from a path tint (14% alpha) to `bg` |
| `Header` | 56 pt bar: back button, optional centred title, optional right slot |
| `Button` | Variants `primary` (ivory), `gold`, `secondary`, `ghost`; sizes `lg` (56 pt) and `md` (48 pt); `loading`, `disabled`, `icon` |
| `IconButton` | 44 × 44 icon button, optionally `framed` |
| `TextLink` | Inline text button |
| `Card` | Rounded surface |
| `Chip` | Selectable pill with `selected` and `locked` states |
| `PathBadge` | A circle in the path colour with its letter |
| `LevelMeter` | 3-segment meter + optional label, `wide` variant |
| `Banner` | Tone (`neutral`, `gold`, `success`, `danger`) + icon + title + body + action |
| `ProBadge` | Gold `PRO` / `ACTIVE` pill |
| `SectionLabel` | Uppercase section heading with optional icon and right slot |
| `ConfirmSheet` | Bottom-sheet modal with a destructive option |
| `FadeIn` | Fade + lift on mount (instant with reduced motion) |
| `Divider` | Hairline |
| `haptic` | `tap()`, `impact()`, `success()` (skipped on web) |

Other components: `ForkTree`, `ForkMark`, `DecisionRow`, `Icon` (22 original line icons: `back, arrow, check, lock, plus, trash, close, settings, history, spark, compare, offline, info, edit, branch, infinity, layers, bolt, alert, question, up, swap`), `Missing` and `Text`.

## Icon and brand

The app icon and the **Fork mark** are original artwork: a single ivory stem splitting into an amber (A) and a teal (B) branch, each ending in a dot. `ForkMark` can draw itself (`progress`), recolour its branches, and dim one side (`highlight`) to show the chosen path in the journal.
