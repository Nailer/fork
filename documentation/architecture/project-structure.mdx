## Files you should never edit by hand

| File | Why | Instead |
|---|---|---|
| `supabase/functions/analyze-decision/schema.ts` | Generated | Edit `src/domain/schema.ts`, then `npm run sync:edge` |
| `supabase/functions/analyze-decision/parse.ts` | Generated | Edit `src/domain/parse.ts`, then `npm run sync:edge` |
| `ios/`, `android/` | Generated by Expo prebuild (git-ignored) | Configure in `app.config.ts` and config plugins |
| `dist/` | Web export output | `npm run build:web` |
