Fork exposes **one HTTP endpoint**, the AI proxy. Everything else runs in-process on the device. This section also documents the data model and the most important internal modules.

## Base URL

```text
https://gwruqdpbugqjrkyfvipa.supabase.co/functions/v1
```

Replace the project ref with your own when you self-host.

## Authentication

The function is deployed with JWT verification. Send the project’s **anon** (public) key in both headers:

```http
Authorization: Bearer <SUPABASE_ANON_KEY>
apikey: <SUPABASE_ANON_KEY>
```

Requests without a valid key get a `401` from the Supabase gateway before they reach the function.

## Conventions

- Request and response bodies are JSON (`Content-Type: application/json`).
- Errors always look like `{ "error": "<code>", "message": "<human text>" }`. Branch on `error`, never on `message`.
- CORS is open (`*`) for `POST` and `OPTIONS`.
- Rate limit: 12 requests per 10 minutes per IP, per instance (configurable).
