## 1. Fix the AI proxy (about 5 minutes)

<Steps>
  <Step title="Get a model key">
    **Recommended:** a Gemini key from [Google AI Studio](https://aistudio.google.com/apikey) (there’s a free tier, and it’s fast).
    Or an Anthropic key from [console.anthropic.com](https://console.anthropic.com) with at least $5 of credit.
  </Step>
  <Step title="Log in to Supabase CLI">
    ```bash
    npx supabase login
    ```
  </Step>
  <Step title="Set the secret">
    <CodeGroup>
    ```bash Gemini
    npx supabase secrets set GEMINI_API_KEY=AIza... --project-ref gwruqdpbugqjrkyfvipa
    ```
    ```bash Claude
    npx supabase secrets set ANTHROPIC_API_KEY=sk-ant-... --project-ref gwruqdpbugqjrkyfvipa
    ```
    </CodeGroup>
  </Step>
  <Step title="Deploy the latest function">
    From the repo root:
    ```bash
    npx supabase functions deploy analyze-decision --project-ref gwruqdpbugqjrkyfvipa
    ```
    <Warning>Don’t add `--no-verify-jwt`. The app sends the anon key, and JWT verification is part of the security model.</Warning>
  </Step>
  <Step title="Test it">
    ```bash
    ANON=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJpc3MiOiJzdXBhYmFzZSIsInJlZiI6Imd3cnVxZHBidWdxanJreWZ2aXBhIiwicm9sZSI6ImFub24iLCJpYXQiOjE3ODI4MTk3NDMsImV4cCI6MjA5ODM5NTc0M30.r-M2bpe7BVPtcwJEU-GYn4H0RGRhEsGxXSuxIVV_FWY
    curl -s https://gwruqdpbugqjrkyfvipa.supabase.co/functions/v1/analyze-decision \
      -H "Authorization: Bearer $ANON" -H "apikey: $ANON" -H "Content-Type: application/json" \
      -d '{"description":"Should I buy a new laptop now or wait a year?","depth":"standard"}' | head -c 400
    ```
    You should see `{"analysis":{"decisionTitle":…` and, at the end, `"provider":"gemini"` (or `anthropic`).
  </Step>
</Steps>

## 3. Publish these docs (about 5 minutes)

1. Sign in at [dashboard.mintlify.com](https://dashboard.mintlify.com) and create a new project (e.g. subdomain `fork`).
2. Install the Mintlify GitHub App on **Nailer/fork**.
3. In **Settings → Git settings**, pick the repo, branch `main`, turn on **Set up as monorepo**, and set the path to **`/documentation`**.
4. Save. Mintlify builds and publishes, and every push to `main` redeploys.

See [Documentation site](/deploy/documentation-site).
