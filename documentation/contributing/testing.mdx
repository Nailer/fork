Jest uses the `jest-expo` preset, ignores `/node_modules/` and `/supabase/`, and loads `jest.setup.js`.

## Mocks (`jest.setup.js`)

- **AsyncStorage** → the official in-memory mock.
- **react-native-purchases** → every SDK method as `jest.fn()`, plus `LOG_LEVEL` and the `PURCHASES_ERROR_CODE` values the wrapper maps.

The AI client is tested by injecting `fetchImpl` and `endpoint` options, so there’s no global fetch mocking and no network.

## What isn’t covered

- Screen rendering and navigation (no component or E2E tests)
- The Deno handler (`index.ts`) itself. Its pure pieces (`prompt.ts`, `parse.ts`, `schema.ts`) are covered.
- Live provider calls

The demo recorder (`scripts/record-demo.mjs`) drives the real web build with Playwright and works as a manual smoke test of the full flow.

## Adding tests

- Put pure-logic tests next to the others in `src/__tests__/`.
- Prefer testing `src/domain` functions directly.
- For the store, call actions through `useForkStore.getState()` and pass explicit `now` values for deterministic time.
- For the AI client, pass `{ fetchImpl, endpoint, timeoutMs }`.
